TheRide — Corporate API Reference

Base URL: http://localhost:3000/api/v1  ·  Auth: Authorization: Bearer <token>  ·  Version: Nov 14, 2026

Journey order

Register (company details) → Verify email → Login → Onboarding-status
→ Complete profile (company address) → Upload documents → Admin review
→ Dashboard → Employee management / Bookings / Wallet

GET /auth/onboarding-status — nextStep values for corporate:

nextStepMeaning
VERIFY_EMAILEnter the emailed code
COMPLETE_PROFILEcompanyAddress not set yet — POST /corporate/profile
DASHBOARDProfile has an address — go to dashboard
A CorporateProfile row is created automatically at registration (profileCompleted: true). Document upload and admin approval happen through the admin panel; document status does not currently gate the nextStep value.

1. Auth

POST/auth/register

Corporate is auto-detected — send company details instead of a role. phoneNumber is optional here (required for drivers/passengers).

{
  "fullName": "Bola Ade",
  "email": "bola@acmeltd.com",
  "phoneNumber": "08031112233",      // optional for corporate
  "password": "Passw0rd!",
  "confirmPassword": "Passw0rd!",
  "companyName": "Acme Ltd",
  "rcNumber": "RC-123456"
}
{
  "success": true,
  "message": "Registration successful. Please verify your email.",
  "email": "bola@acmeltd.com",
  "role": "CORPORATE_ADMIN",
  "companyName": "Acme Ltd",
  "rcNumber": "RC-123456"
}

POST/otp/verify-email  ·  POST/auth/login

{ "email": "bola@acmeltd.com", "code": "4821" }
{ "identifier": "bola@acmeltd.com", "password": "Passw0rd!" }
{
  "success": true,
  "message": "Login successful.",
  "token": "eyJhbGciOi…",
  "user": {
    "id": "c01d…",
    "email": "bola@acmeltd.com",
    "role": "CORPORATE_ADMIN",
    "emailVerified": true,
    "isVerified": false,
    "status": "ACTIVE",
    "companyName": "Acme Ltd",
    "rcNumber": "RC-123456"
  }
}

Password reset — corporate gets the web link only

POST /auth/forgot-password { "email": "…" } sends an email with a button to the corporate portal (no 4-digit code). The portal page calls:

POST /auth/reset-password/:token    { "newPassword": "…", "confirmPassword": "…" }

4. Employee management

Employees are existing passenger users attached to the company. userId is the user's UUID.

POST/corporate/employees 🔐

{
  "userId": "4b1e8f0a-…",          // required, UUID of an existing user
  "department": "Operations",      // optional
  "employeeId": "ACM-014",         // optional
  "position": "Field Officer"      // optional
}

PATCH/corporate/employees/:id 🔐

{ "department": "Finance", "position": "Analyst", "status": "ACTIVE" }  // status: ACTIVE | INACTIVE

Other employee endpoints

  • GET /corporate/employees 🔐 — list
  • GET /corporate/employees/:id 🔐 — detail
  • DELETE /corporate/employees/:id 🔐 — remove
